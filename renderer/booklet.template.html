                    Jev ranks the models within your chosen provider for each task by catalog quality, estimated price, and your project's measured timing, errors, ratings and reported costs; missing evidence stays unknown.         About these controls
        
                    
          
                    Autopilot
                    
          
                    The master switch for the assistant's queue. On each pass the assistant looks for ready tasks, starts them while a worker slot is free, and verifies what came back. Turning it off stops new work from starting; jobs already running finish normally.
                    
          
                    Parallel builds
                    
          
                    How many builds may run at the same time. Machine managed starts work while the app stays responsive and backs off when the machine is busy. A manual limit (1–3) caps concurrent builds but never starts or pauses anything by itself.
                    
          
                    Build mode
                    
          
                    Auto build starts eligible tasks as soon as a worker is free. Verify first holds every new or changed brief for your approval, so you decide what gets built. Switching never interrupts a running job.
                    
          
                    Agent mode
                    
          
                    How agents coordinate. Swarm uses one builder per task across the ready queue; Cluster adds planning, review and scoped delegation for one shared task. Current work finishes when you switch. The same selector sits in the node tree toolbar under Agents for quick changes.
                    
          
                    New work
                    
          
                    The master switch for starting anything new — queued tasks, builds and work the assistant suggests — lives with the Assistant. Off pauses admission; running jobs, replies and your answers to questions still work.

                                                What the marks mean
                                                
        
                                                  
          
                                                • Colour is the stage a part belongs to: intake, checks, planning, assistant, routing, build, decisions. A wire takes the colour of the part it leaves.
                                                  • 
          
                                                • Map rulesThe map itself decides here. Editing it changes behaviour as soon as the map is saved.
                                                  • 
          
                                                • NoteA drawing only: saved and shown, but nothing runs it.
                                                  • 
          
                                                • Moves a real switch when the map goes live. Every other part holds settings for a stage the studio already runs.
                                                  • 
          
                                                • A dashed wire is a feedback wire: what it carries lands on the next pass.
                                                  • 
          
                                                • A red ring is a required end with nothing wired, and a red part or wire is a problem to fix before the map can go live.
