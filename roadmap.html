Roadmap

What's done, and what's next

Every release so far, what's being built right now, and what's planned, including the community plan. Want something that isn't here? Ask for it.

Latest release: 0.4.4, 27 September 2026 · Roadmap updated 29 September 2026

The 0.4.5 scope

Small wins around the work already on main. 0.4.5 is not published yet, and has no release date. The download stays on 0.4.4.

Will ship in 0.4.5

The setup helper and Configuration index, clearer agent status and live Vibe progress, the visible Fleet page, PC setup and sharing, Friends in the main menu, and compact Task and Ideas cards. See the full list.

Outside 0.4.5

Faster agent sends, retained logs, the faster launch and Friends 2.0 target 0.4.6; Fleet lanes and missions are planned for it. The full menu overhaul and the remaining card cleanup have no release target. Branch work on Build desktop, media and ratings is still undecided. Linux, voice, credits and creative-tool bridges stay later.

Still needs the hub

Rooms, Listen together, friends’ playdates and cross-PC file claims need the community rooms hub and Discord link to be online. Discord remote controls also need the bot’s matching support. Shipping the app does not switch these services on. See what is rolling out.
