0.5: the next release

Everything built on main since 0.4.4, including what was planned for 0.4.5 and 0.4.6 (they were folded into 0.5), a new layout that puts Social and Studio in one frame, and Friends on a relay that needs no setup. The download is still 0.4.4, and 0.4.4 will update to 0.5 by hand: the steps come with the release.

  • The 0.5 layout: the Map, Team, sessions, tabs you pin, one Inbox
  • Friends with no setup: The Lobby, rooms, the Project hub, a weekly Build Jam, credits you earn by playing
  • See what a worker changed, and take it back
  • Connectors, skills any way you want them, thinking that steps up when a job is stuck
  • Windows notifications, Report a problem, What’s new after an update

Studio is moving to Rust

From Electron to Rust with Tauri 2, in three stages. The app keeps working at every step, and the screens, settings and saved keys stay the same. The download is still the Electron build.

  1. 1 · The Rust hostWindow, tray, dialogs, notifications and saved keys in Rust. Runs from source today.Built on main
  2. 2 · The engine moves into RustPart by part, each held equal to the code it replaces. Nine parts so far.In progress
  3. 3 · One Rust programA release with only the Rust host, and a bridge release for today’s installs.Planned

What stays the same

  • The screens and the keys you use
  • Your settings, projects and saved API keys
  • The Electron build keeps shipping until the switch
