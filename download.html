Get Mefi Studio for Windows

Free and open source. One zip, no installer and no Studio account: unzip it, open it and pick a project folder.

  • Portable. The app and its work stay in the folder you unzip. Nothing else gets installed.
  • Private by default. No telemetry. Your projects stay on your PC, and an AI service you connect only gets what you send through it.
  • Checkable. Every release comes with a SHA-256 file, so you can confirm the zip is the one that was published.

Release notes

On 0.4.4? Your next update is by hand

The Update button in 0.4.4 can download a new release but can't install it: its install step doesn't run after Studio closes. 0.5, the next release, fixes that, so when it comes out, move to it by hand this once. The 0.5 release will say how; these are the steps as they stand today:

  1. Quit Studio. Closing the window keeps it in the tray, so right-click the tray icon and choose Quit.
  2. Unzip the new release into a new folder.
  3. Copy everything in your old resources\app\data folder into the new one, except curated.json and models.json, which are the new build's model lists.
  4. Open the new Mefi Studio AI+.exe. Settings, saved keys and your project list live in Windows' app data, so they come along by themselves. Keep the old folder until you're happy.

Your tasks, ideas, plans and conversations come along in the data folder. The app still says Mefi Studio AI+ in its window title and file names on purpose, so your settings carry over.

Install

Three steps, about two minutes

There's no installer to run. You download a zip, unzip it and open the app inside.

  1. Download the zip

    Use the button above to get Mefi-Studio-AI+-v0.4.4-win32-x64.zip (157 MB). Grab the SHA-256 file too if you want to check it.

  2. Unzip it somewhere you can write

    Right-click the zip and choose Extract All…. Pick a folder you own, like Documents or your Desktop, not Program Files: Studio saves its tasks, plans and chats inside its own folder.

    Keep the Mefi Studio AI+ folder together, and don't open the app from inside the zip.

  3. Open it, and let Windows run it

    Double-click Mefi Studio AI+.exe. The build isn't code-signed yet, so Windows SmartScreen may say it protected your PC. Choose More info, then Run anyway. Windows usually asks only the first time.

    More info→Run anyway

Then choose a project folder on the launch screen and pick Open studio (agents stay off) or Open and start agents. Start here walks you through the rest in seven short stops. Your first project in the wiki →

What you need

A Windows PC. The rest is up to you.

Studio itself is free. To build things it works with a coding tool or AI service you choose, on that service's own plan or key.

Needed

Windows 10 or 11, 64-bit

Studio is built for Windows, and it protects saved keys with the Windows keystore. There's no macOS build. A Linux build is on the roadmap Planned

Needed

Some disk space

About 157 MB to download and roughly 400 MB once unzipped, plus room for the work Studio keeps for your projects.

Recommended

Git

Studio reads your project through Git to check work that claims a commit, and Friends › Your PCs uses it to sync your PCs. Without it, those checks are skipped.

Optional

A coding tool, to build

OpenCode, Claude Code, Codex, Grok or Antigravity. If one is already installed and signed in, Studio finds it on first launch, even one you add while Studio is open. Without one you can still plan and chat, but builds can't start.

Optional

An AI for chat and plans

An API key (z.ai, OpenCode Go or Zen, OpenRouter) or a local model in LM Studio or any OpenAI-compatible server. Or let your coding tool's login run everything with Use for the whole studio.

Not needed

Node.js, an account or Discord

The zip brings everything it runs on. There's no Studio account to make. The Discord is the easiest place to ask for help, and it's never required.

Check the download

Make sure the zip is the real one

Every release has a .sha256 file next to the zip. Studio's own updater checks it before it installs anything, and you can check it yourself.

Open PowerShell, go to the folder with both files and run these lines. True means the zip matches what was published. False means download it again.

PowerShell
cd "$HOME\Downloads"
$zip = "Mefi-Studio-AI+-v0.4.4-win32-x64.zip"
$want = (Get-Content "$zip.sha256").Split(" ")[0]
(Get-FileHash $zip -Algorithm SHA256).Hash -eq $want

Updating

Studio tells you when there's a new release

The app looks for new releases on GitHub every 20 minutes. When one is out, the menu shows an update badge and a notice says so. To look right away, open Settings › System › Updates and press Check GitHub.

Update downloads the new build, checks its SHA-256, and swaps the app files after Studio closes. Your data folder is never overwritten.

Running from source? Pull main. Live update applies the changes while Studio runs.

For developers

Run it from source

You need Node 24 with npm, and Git. npm ci downloads Electron once, about 110 MB. Source runs what's on main, so it has the newest work before it's released, and it changes often.

Run npm start from a normal shell. If ELECTRON_RUN_AS_NODE is set, Studio stops and tells you how to fix it. A source install and the portable app share settings and keys on the same Windows account, so only one of them runs at a time.
