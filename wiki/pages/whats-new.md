# What's new in 0.4.3

[Download 0.4.3](../../download.html) for Windows or read the [release notes](https://github.com/nateecho32-stack/mefi-studio/releases/tag/v0.4.3).

## Released in 0.4.3

- **Media and links:** keep an Up next queue for copied links and YouTube results, browse videos in the built-in explorer, and restore playback, volume, mute and tree placement.
- **Live tree controls:** choose Steady, Music, Video or combined movement; use ring, wave and spiral layouts; and tune size, spacing, rotation, position, brightness, outlines and transparency.
- **Files and planning:** drop text and code files into Home, Vibe and Plans. Plans remember their selected step, Vibe keeps per-project drafts, and planning reads fresh project context.
- **Tools by agent role:** configure web search, project reads and MCP tools per role, with MCP attachments available to OpenCode and Claude workers.
- **Zen tree tour:** park at the right edge of Command view to start a slow tour, then move, click or type to return to the controls.

Studio stores project records and settings locally. Connected AI providers and coding tools may receive prompts and project context according to your configuration. Discord linking is optional.

## Released in 0.4.2

- **Vibe mode:** talk through ideas, create tasks, and see what is building, what needs your attention and what finished. Answer agent questions, approve builds, retry blocked work, and start or resume agents from the same workspace.
- **Remastered node styles:** all eight looks have distinct motion, activity effects and connections that meet each node's edge. Five styles are included; three are in the optional Void collection.
- **More dependable planning:** archive and restore plans, keep saved answers after failed replies, and preserve approvals when renaming a plan or saving an unchanged specification.
- **Clearer decisions and efficiency:** see why work is blocked, with fewer repeated offers and more useful task counts. Builders get focused task context, while idle rendering and background checks avoid repeated work.

## Released in 0.4.0: the Agent Brain update

- A visible pipeline for each task, with steps, delegated agents and reports returning to the parent.
- The Playbook records pipeline recipes from prior work.
- A project map connects systems, parts and files in the Command view.
- Plans turn an idea into a reviewed specification and tasks.
- Floating media, music, radio and links stay close to the work.
