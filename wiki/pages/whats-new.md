# What's new in 0.4.4

[Download Mefi Studio 0.4.4 for Windows](../../download.html) or open the [GitHub release](https://github.com/nateecho32-stack/mefi-studio/releases/tag/v0.4.4).

## Easier setup

**Start here** can install Codex, Claude Code, Grok or Antigravity, open sign-in and check the connection. **Use for the whole studio** applies that account to chat, project mapping, planning, agents and coding.

**New app** creates a project folder under Mefi Apps, initializes Git and sends your description as its first build request.

[Set up your first project](getting-started.md).

## Work you can follow

**Build it** in Vibe can split a larger request into two to six steps. A **Plan in flight** card follows the work, and **Make it one task** lets you return unstarted steps to a single task.

When you reopen a project, Studio reports commits, edits and supported coding sessions from while it was closed. It checks queued tasks against those changes before starting them, helping you catch work that may already be done.

Finished tasks have **Ask for a change** for another pass. Tasks, Plans, Ideas, Team and Settings now open as compact panels within Vibe.

## More control over agents

Permission choices are **Always ask**, **Accept per task**, **Auto** and **Elevated only**. Automatic decisions include an explanation and an Undo action. You can turn permission learning off or clear what it learned.

The optional desk companion can answer routine agent questions and show its decision. Requests reserved for you remain in **Needs you**.

## Appearance and media

All themes and node styles, including the Void collection, are free. Select them in **Appearance**; Discord membership is not required.

The media player and saved queue share one panel. **Browse here** opens websites inside the player, and local music has record artwork.

## Across PCs

**Friends › Your PCs** shows how this PC compares with the project's default branch on GitHub. **Sync this PC** pulls and pushes eligible changes without force-pushing. Local conversations, settings and credentials remain on their own machine.

## Other changes

**Trace**, under **Agents › Live**, brings Studio's log channels into one viewer. **Restart now** saves agent work before relaunching. This release also includes bug fixes and Command view performance improvements.
