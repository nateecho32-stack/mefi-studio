# Mefi's Studio AI+ website

Public site: https://nateecho32-stack.github.io/mefi-studio/

GitHub Pages publishes the root of this repository's `gh-pages` branch. The `main` branch holds the Electron application. This site includes the download page, wiki and the 40-second Studio showreel for the published 0.4.2 release.

Preview with a loopback-only static server. Edit these static files on `gh-pages` and push to update the site. No build tooling or secrets are required. The download page provides direct 0.4.2 ZIP and checksum links without JavaScript, then checks GitHub for a newer release. If that lookup fails, the published download remains usable.

0.4.2 introduces Vibe mode, remastered node styles and planning improvements. The Agent Brain update shipped in 0.4.0. The showreel uses Studio's node painters and sample tasks to illustrate the workflow; it contains no live user data. Ready-to-post Discord copy is in `media/social-posts.md`.
