# Mefi's Studio AI+ website

Public site: https://nateecho32-stack.github.io/mefi-studio/

GitHub Pages publishes the root of this repository's `gh-pages` branch. The `main` branch holds the Electron application. This site includes the download page, wiki and the Studio showreel and release notes for 0.4.3.

0.4.3 adds media queues and a YouTube explorer, flexible live-tree movement and display controls, file-aware planning, and per-agent web, project-read and MCP tools.

Preview with a loopback-only static server. Edit these static files on `gh-pages` and push to update the site. No build tooling or secrets are required. The download page provides direct 0.4.3 ZIP and checksum links without JavaScript, then checks GitHub for a newer release. If that lookup fails, the published download remains usable.

0.4.3 adds media queues and a YouTube explorer, customizable live-tree movement and display controls, file-aware planning and per-agent tools. Earlier releases introduced Vibe mode and the Agent Brain. The showreel uses Studio's node painters and sample tasks to illustrate the workflow; it contains no live user data. Ready-to-post Discord copy is in `media/social-posts.md`.
