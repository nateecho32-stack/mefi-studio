Mefi's Studio AI+ 0.4.3 expands media playback, live tree controls, project-aware planning and per-agent tools.

### Media and links

- Keep an **Up next** queue for copied links and YouTube results. Play items immediately, queue them next, or remove them; supported sources advance automatically when playback ends.
- Browse and play YouTube videos with the built-in explorer. Restore recent playback, volume, mute and tree placement after restarting Studio.
- Adjust tree and video transparency separately, and tune node and connection brightness independently. Optional outlines improve node contrast.
- Hover the media control to reach source settings. Zen keeps its canvas clear and offers a slow tree tour when you park at the right edge of Command view.

### Shape the live tree

- Choose Steady, Music, Video or combined movement. Ring, wave and spiral layouts respond to the selected media, with controls for size, width, height, rotation, position and spacing.
- Tune music movement and video-region placement separately. Tree controls are shared by Appearance and Audio reactions.

### Bring project context into planning

- Drop text and code files into Home, Vibe and Plans, or choose files to add their editable contents to a draft.
- Plans remember the selected plan and step per project. Vibe keeps a separate draft for each project.
- Planning reads fresh project excerpts, README and build context, and explicitly named files. Resumed interviews retain earlier answers.

### Tools by agent role

- Configure web search, project reads and individual MCP tools per role in Agents setup.
- Shared research turns are available across Studio's AI surfaces. OpenCode and Claude workers can use MCP attachments within the role's selected tool allowlist.

### Small refinements

- Copied-link detection and URL visibility have saved controls; hiding URLs also masks links in clipboard, recent and queue views.
- A machine-local style preference can retain Void themes and node styles across app updates without changing release defaults.
- Media controls stay usable over video, settings no longer interrupt playback, and completed tasks fade the video gently.

Already using a portable build? Check **App updates** for 0.4.3. Studio verifies the download checksum and preserves local data.
