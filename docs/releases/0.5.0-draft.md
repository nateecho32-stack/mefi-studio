# Mefi Studio 0.5.0 — release draft

The current validation build is **0.5.0-rc.1**. This document prepares the
0.5.0 release; it does not announce a public download or a release date.
The public download remains 0.4.4 until the final release is published.

## Updating from 0.4.4

**0.4.4 needs a manual update.** Its updater cannot install this release.

1. Save work, let running agents finish or stop them, and quit Studio,
   including its tray process.
2. Make a separate backup of the entire existing portable folder, especially
   `resources/app/data`. Also back up Studio's profile/settings directory,
   its configured local storage, and any project folders you need to restore.
   Keep these private; they may contain credentials and personal work.
3. Extract the new Windows ZIP into a fresh folder. Keep the old installation
   and backup intact. Do not mirror a clean release over the old data folder.
4. Copy your old `resources/app/data` records into the new installation's
   `resources/app/data`, preserving its project records, history and local
   state. Retain the new build's `curated.json` and `models.json` catalogs.
   Keep the existing Studio profile and configured local storage in place.
   The application name is unchanged so the same Windows account continues
   using its existing settings. Machine-bound credentials may require a new
   sign-in when moving to a different PC.
5. Launch the new executable. Check your projects, task history, provider
   connection and settings, then restart once and confirm they persist.
   Keep the previous build and backups until those checks succeed.

The candidate's updater and rollback rehearsals use scratch installations.
They do not establish that a production GitHub download/restart or a real
0.4.4 owner profile migration has been exercised. Those remain release checks.

## What changes

- Friends brings Rooms, Here now, the existing chat and composer together with
  your actual project, the room player and the current Build Jam. Small windows
  reveal its side panels; reconnecting keeps unsent drafts. Invitations and
  the Lobby roundup remain reachable. Listening opens the existing player;
  shared links reveal their destination, and supported players load only when
  you choose.

- Shared images are reviewed locally, re-encoded without camera metadata, and
  shown to recipients only on request. The private service must support uploads
  and enforce room access. Cosmetic swaps review the exact two-sided offer and
  acceptance; the compatible private service controls eligibility and ownership.
  These client changes do not deploy the service or grant credits, rank or paid
  access.

- Pets and stickers have a collection home with baby-to-adult appearances,
  care and traits, reviewed crate odds, market orders and creator forms.
  Nine Studio sticker designs are bundled. Ownership, free base copies,
  membership rights and trades require the compatible private service;
  installing this client does not grant items or enable that service.

- A compact session sidebar keeps New task beside the project, with Sessions,
  Backlog and filtering together. Keyboard navigation reveals the focused
  task or project, including short windows and increased interface scale.
- Fleet shows state, elapsed time, last action and the current tool. Waiting
  questions show their blocker immediately and sort oldest first within their
  priority. Quiet tool activity is described without declaring it failed.
- Needs you and setup guidance explain what is missing and which runtimes
  the project needs. The existing surfaces remain their home.
- Short-window navigation retains Home, Work, Agents and Friends.
  Ctrl+Shift+T reopens the last closed tab.
- The selected V-and-star artwork is preserved in the window, tray and
  executable. Electron and Rust host bridges keep the fullscreen preference.
- Development updates follow GitHub Actions artifact responses correctly.

The [changelog](../../CHANGELOG.md) retains the full 0.5 development history
and the candidate's curated What's New entries.

## Social and launch readiness

The public website labels its guided experience as a simulated demo. Its
launch offers are planned, and checkout is unopened. Private account,
subscription and reward-authority code is separate from this desktop build.
Google configuration, the private gateway, billing integration, reviewed
account migration and real two-PC social verification remain prerequisites.
This candidate activates no subscription policy or new credit awards.
