Mefi's Studio AI+ 0.4.2 brings a simpler way to manage AI-assisted work, remastered visuals for the live agent view, and improvements to planning and reliability.

### New: Vibe mode

Talk through an idea or turn it into a task from one home screen. See what is building, what needs your attention, and what recently finished.

Answer agent questions, approve builds, retry blocked work, and start or resume agents directly from Vibe. Tasks, Plans, Settings, and other pages stay within Vibe's navigation; switch to Build whenever you want the full workspace.

### Remastered node styles

All eight node styles have been reworked with distinct animation, clearer activity states, and matching connections and effects. Classic orbs, Soft glass, Minimal, Halo, and Crystal are included; Singularity, Prism, and Sigil belong to the optional Void collection.

Reduced-motion settings remain supported, and connections now meet each node's edge.

### More dependable planning

- Archive and restore plans without deleting them.
- Keep saved answers when an AI reply fails, then continue without submitting them twice.
- Preserve approvals when renaming a plan or saving an unchanged specification.
- Handle malformed suggestions without discarding the entire batch.

### Reliability and efficiency

- Test processes are no longer mistaken for hung processes after a brief pause.
- Agent decisions show clearer reasons for blocked work and avoid repeated offers.
- Builders receive focused task context instead of the entire task board.
- Rendering and background checks avoid unnecessary work when the workspace is unchanged.

### Download and update

Download **Mefi-Studio-AI+-v0.4.2-win32-x64.zip** from the [release assets](https://github.com/nateecho32-stack/mefi-studio/releases/tag/v0.4.2), extract the complete folder, and launch **Mefi Studio AI+.exe**. Node.js is not required for the portable build. The accompanying `.sha256` file contains the ZIP's SHA-256 checksum.

Already using a portable release? Check **App updates** for 0.4.2. Studio verifies the download before installation and preserves your local data.

Studio stores project records and settings locally. Connected AI providers and coding tools may receive prompts and project context according to your configuration. Discord linking is optional.
