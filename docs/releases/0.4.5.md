**Mefi Studio 0.4.5 - a new name, one setup helper, and PCs that stay in step**

### Updating from 0.4.4

Studio 0.4.4 cannot update itself: Update downloads the build, Studio closes, and nothing installs. The helper is fixed in 0.4.5, so later updates work in the app. To move up now:

1. Download `Mefi-Studio-AI+-v0.4.5-win32-x64.zip` from the release assets, close Studio, and extract the zip to a **new** folder.
2. Copy your old `resources\app\data` contents into the new `resources\app\data`, except `curated.json` and `models.json`, which the new build carries.
3. Open `Mefi Studio AI+.exe` from the new folder.

Settings, saved keys, the project list and your Discord link live in `%APPDATA%\Mefi's Studio AI+` and carry over on their own.

**A new name.** Mefi's Studio AI+ is now called Mefi Studio on the site, in the README and in these notes. Bring an idea. Find your people. Make it together. The app itself still says AI+ in its window title, boot screen, `Mefi Studio AI+.exe` and zip name, on purpose, so every install keeps its settings.

### Setup and accounts

- **One setup helper** opens on a new install, and once after this update. Pick Quick setup or Everything, which walks every setting that decides what agents do.
- **Finds the login you have.** Set up automatically notices a Claude Code, Codex or Grok login, and with no AI connected Home and Vibe say so. Add extra Claude Code or Codex logins and work moves to the next when one hits its usage limit.
- **Configuration** (Ctrl Shift ,) puts every setting in one searchable place, with an Interface scale from 70% to 150%. **Habits** give each agent short rules of behavior.

### Several PCs

- **Friends › Your PCs.** **Set up this PC** checks Git, the GitHub CLI, Node.js and your sign-in; **Get a project from GitHub** clones one; **Keep this PC up to date** (on by default) brings in work another PC pushed when nothing of yours is in the way.
- **Share between my PCs** sends what you choose through a private GitHub repository, encrypted for your paired PCs. **Share with friends** saves one item as a `.mefishare` file, previewed first; a friend's file is reviewed before you keep it.
- **Start with Windows** (off by default) opens Studio in the tray on your last project at sign-in.

### Smarter agents

- **Agents say why they are not working**, in one status that Home, Vibe, Command and chat share.
- **When Studio opens:** pick whether agents resume, start or stay off. Command view no longer jumps in after five quiet minutes unless you turn that on.
- **Watch Mefi think:** Suggest a next step and Build it show their stage, files read and steps planned. **Build on your app with MEFI** offers Modify, Experiment, Fix and Improve.
- Asking **what changed while I was away** works even without a key.

### GitHub from inside Studio

- **A Git chip beside the project name** says whether the open project is in sync with GitHub, has work to push or pull, or is only on this PC. Click it for one plain sentence and the one button that fits: Push, Pull, Publish to GitHub, Sign in or Save and push. Studio never commits for you: with unsaved files, Save and push lists them for you to tick, and it stops private keys and other secrets before anything is saved. Publishing makes a private repository unless you type the public name back.
- **Start a new app on GitHub.** New app can publish the folder as a private repository, link one you already have, or keep it on this PC. A failed publish never loses the folder.
- **A quieter launch screen.** One Open button and a Start agents switch, when each project was last opened and its GitHub state, and Open a folder, Start a new app and Get from GitHub at the foot.

### Your team, live

- **Live › Fleet** draws your team as pods of seats with the wires between them (a handoff, a check, a question for you), with a table, a recent feed and a health list. Click a seat to see what it is doing, its runs, and to stop the run you are looking at.
- **Friends** is in the main menu with direct links to Rooms, Your PCs and Playground, and **Ideas** use the same compact cards as the Task board.
- **The Windows app has Studio's name and icon** in Task Manager, Properties and SmartScreen, instead of Electron's.

### Everyday Studio

Plans show one step at a time, the Task board is calmer, typing goes to the menu that is open, and stopping a worker, dropping a task or deleting a room asks twice. Studio no longer sticks on its start screen when its window is covered or in the tray.

This release has no rooms hub built in. Rooms, friends' Playground playdates, Listen together, cowork file claims and the Discord remote do nothing until you enter a hub address and the Mefi Studio Link app id in Settings › Community › Connection details and link your Discord; the remote also needs a hub with it turned on.

The `.sha256` file beside the zip holds its SHA-256 checksum. Studio stores project records and settings locally; connected AI providers and coding tools may receive prompts and project context as you configure them.
