Mefi Studio is a free Windows app for building with coding agents, with a community for sharing ideas and work in progress. Join us in the [Void Engine Discord](https://discord.gg/xgfKc5pVxG) to meet other makers, try our new Studio bot, or just hang out.

Version 0.4.4 makes setup a single sign-in, helps agents pick up existing work, and includes every theme and node style for free. [Explore Studio](https://nateecho32-stack.github.io/mefi-studio/) or follow the [setup guide](https://nateecho32-stack.github.io/mefi-studio/wiki/#/getting-started).

### Getting started

- **Use a subscription you already have.** Start here can install Codex, Claude Code, Grok or Antigravity, sign you in and check the connection. **Use for the whole studio** then routes chat, mapping, planning, agents and coding through that one account.
- **Start a new app in one step.** Name an app and describe it. Studio makes the folder under Mefi Apps, starts git, opens it and sends the description as the first request.
- **Keep every PC in step.** Friends › Your PCs shows whether this PC matches the project's default branch on GitHub and lists anything that has not reached it. **Sync this PC** pulls and pushes without force.

### Smarter agents

- **Big requests become steps.** **Build it** in Vibe decides whether a request is one task or two to six steps, each leaving the project working. **Make it one task** undoes the split.
- **Nothing gets built twice.** When you reopen a project, Studio reports the commits, edits and Claude Code or OpenCode sessions from while it was closed, and checks queued cards against that work before a worker takes them.
- **Permission modes.** Choose Always ask, Accept per task, Auto or Elevated only. Automatic decisions have a Why and an Undo, and Mefi learns from your answers. With the desk on, your companion settles routine questions and says what it chose; risky asks always wait for you.

### Everyday Studio

- **Vibe menus.** Tasks, Plans, Ideas, Team and Settings open as compact panels inside Vibe. Send finished work back with **Ask for a change**.
- **Media.** The player and saved queue share one panel, websites open inside the player with **Browse here**, and local music gets record artwork.
- **Trace.** Studio's logs as channels in one viewer, under Agents › Live.
- **Updates and fixes.** **Restart now** saves your agents' work before relaunching, plus a whole-app bug hunt and a lighter Command view.

Studio stores project records and settings locally. Connected AI providers and coding tools may receive prompts and project context according to your configuration. See the [changelog](https://github.com/nateecho32-stack/mefi-studio/blob/main/CHANGELOG.md) for the full list.
