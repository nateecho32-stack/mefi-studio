New in 0.5

The 0.5 layout, up close.

Social and Studio, the two modes (Vibe and Build before 0.5), share one frame: your sessions on the left, the work in the middle, an inspector beside it, tabs on top and a status bar below. It is Studio’s only layout from 0.5.

Studio: your tasks as sessions

Every task is a session with a thread: the brief, each run with its steps, your notes and questions, and what the worker said.

  • Grouped as Needs you, Running, Review, Queued and Done.
  • An inspector with Plan, Changes, Checks, Preview and Agent.
  • A box for a Note, an Ask or a Change, with pictures and the @ # / picker.

Today: Social’s calm home

Social opens on Today: say what you want next, and keep an eye on what needs you, what runs, what to review and what is done.

  • Answer a question or a permission from its card.
  • Mefi’s own decisions show with an Undo.
  • The same frame, tabs and status bar as Studio mode.

One Inbox for everything waiting on you

Questions, permissions, approvals, reviews and stopped tasks, in one list that every count in the window agrees with.

  • The recommended answer comes first, with Mefi’s reason.
  • Decide later, or answer in your own words.
  • Ctrl J opens it from anywhere; a Windows notification opens it too.

See what changed, and take it back

After a worker runs, the inspector lists the files it changed. Accept them, or revert one file or the whole attempt.

  • A private before and after copy of the folder, so a revert can be undone.
  • Lint and typecheck after an attempt, as advice.
  • Pictures on a message, read back in the thread.

Questions that wait for you, not on you

When a worker needs a decision, the question sits above the box with its options, Mefi’s suggestion and why.

  • Pick an option, answer in your own words, or decide later.
  • The plan, brief and acceptance checks stay beside it.
  • Every saved change to the brief is kept as a version.

Search, and everything else, in one place

Ctrl K finds sessions, ideas, pages and actions, and can add work: type “task …” or “idea …”.

  • It starts with what you used last.
  • Tabs you add and pin, which Studio keeps tidy.
  • Ctrl T, Ctrl W, Ctrl Tab and Ctrl 1 to 9.

Size and density, with a live preview

Make text and information bigger or smaller and watch a miniature of the window change before you apply it.

  • Interface scale, text size, three densities and three detail levels.
  • No more flipping back and forth to check a setting.
  • Ctrl +, Ctrl − and Ctrl 0, remembered.

Under the hood

Studio is moving to Rust.

Studio is moving from Electron to Rust with Tauri 2, in stages. The interface stays the same, and so do your settings and saved keys. The app keeps working at every step, and each part that moves gives the same answers as the code it replaces, held equal by tests that run both.

Started 3 October 2026. The download is still the Electron build, and the switch has no date yet.

Follow it on the roadmap →

    The Rust host

    Rust runs the window, the tray, dialogs, notifications, saved keys and the page’s bridge, with the engine beside it. It already runs from source, and a portable build can ship on it.

    The engine moves into Rust

    Part by part: so far the session store, sync and worktrees, the file picker’s search, the Git chip, Skills, pictures, Revert, and settings and keys. Early result: the usage ledger’s repeat reads are about nine times faster.

  3. 3

    One Rust program

    A release carries only the Rust host, with no Node runtime beside it. One bridge release carries today’s installs across.

What Studio is

A studio for making things, with company.

Describe what you want and agents build it in your project. You stay in charge, and people are close by when you want them.

Build with agents

Type an idea, a fix or a question. Build it puts coding agents to work in your project folder, and finished work waits in Review until its checks pass.

New in 0.5

Friends in Studio

The Lobby shows who is online and what was shared this week. Rooms have a chat that reads like a chat app: hangout rooms for up to 25 people and cowork rooms for up to 10, joined with a short invite code. Listen together plays one link for everyone in a room, at the same point.

It all runs on the Mefi Studio relay, a free service built into Studio, so there is nothing to set up: sign in with Discord once. The relay keeps no chat.

New in 0.5

The Project hub

Share what you make as a card and play what friends make. Playing someone else's project for two minutes earns you both credits, which raise your rank and can put a project at the top of the hub for a day. A weekly Build Jam and co-work hours run by themselves.

Credits are only earned: never bought, and never for inviting people or for Discord activity. Every theme and node style stays free. Cosmetics, creator styles and shared mixes are still planned, so come and help shape them.

Get started

Up and running in three steps.

Studio is a portable app: there is no installer and nothing else to set up first.

Download page →

  1. Download the zip

    Get the Windows zip from the latest release.

  2. Unzip and run

    Right-click the zip, choose Extract All, keep the folder together and open Mefi Studio AI+.exe.

  3. Get past SmartScreen

    The build isn't code-signed yet, so Windows may warn you the first time. Choose More info, then Run anyway.

Questions

Good to know

More answers in the wiki's FAQ, or ask in the Discord.

Is Mefi Studio free?

Yes. It's open source under the MIT license, and every theme and node style is free. The AI services you connect may charge for their own use, so you can also use a subscription you already have or a local model.

Can I join before I have something to show?

Please do. Bring an unfinished idea, ask a question, give someone feedback or just hang out. You don't need to download Studio to take part.

Do I need Discord to use Studio?

No. Discord is the easiest way to meet the community, but Studio works without it and has no account of its own. Signing in with Discord inside Studio is optional. The Lobby, Rooms and the Project hub use that sign-in to know who you are; the rest of Studio never needs it, and ways for friends to connect without Discord are planned.

What do I need to run it?

Windows 10 or 11. To build, connect a coding agent: Studio's first-run welcome can install Codex, Claude Code, Grok or Antigravity and sign you in. A Linux build is planned.

Will agents change my files without asking?

Agents run real commands in the project folder you choose, so you decide how much they do alone. Always ask makes every new task wait for your OK, and Auto, the default, lets routine work run. Every automatic choice comes with a Why and an Undo.

What do the labels mean?
  • In Studio in the download today.
  • New in 0.5 new in 0.5, the latest release.
  • Rolling out built, and switches on once the Studio bot’s side is live.
