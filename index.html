Read the showreel overview

An idea becomes a task. Agents appear in the live tree as work moves through queued, running, verifying and done. Eight node styles and eleven themes let you shape the workspace. Studio uses check, test and audit gates for its own releases, stores project records locally and has no usage telemetry. Your chosen AI providers receive requests. No Studio account is required.

WHAT'S NEW IN 0.4.3

More control over how work takes shape.

01 / MEDIA

Keep playback moving

Queue copied links and YouTube results, browse with the built-in explorer, and restore playback, volume and tree placement.

02 / TREE

Shape the live view

Choose music and video movement, ring, wave or spiral layouts, and tune position, brightness, outlines and transparency.

03 / PLANNING

Bring in project files

Drop text and code into Home, Vibe and Plans. Drafts and plan progress stay with each project, and planning reads fresh project context.

04 / AGENTS

Choose tools by role

Set web search, project reads and MCP tools for each agent role, including supported OpenCode and Claude workers.

05 / ZEN

Tour the tree

Park at the right edge of Command view for a slow tree tour, then move, click or type to return to the live controls.

06 / LOCAL

Keep your preferences

Playback and display settings persist locally; local style unlocks remain separate from release defaults.
